# Karvinen 2025: Wireshark – Getting Started

* Wireshark on verkkoliikenteen analysointiin tarkoitettu ohjelma, jolla voidaan kaapata ja tutkia verkkopaketteja.

* Wiresharkilla voidaan tarkastella verkkoliikennettä eri verkkoliitännöistä sekä tallentaa kaappauksia myöhempää analysointia varten.

* Ohjelmassa voidaan käyttää erilaisia suodattimia, kuten dns, tls ja http, joiden avulla voidaan tarkastella tiettyjä protokollia.

# Karvinen 2025: Network Interface Names on Linux

* Linuxissa verkkoliitännät voivat olla fyysisiä tai virtuaalisia. Esimerkiksi loopback-liitäntää käytetään tietokoneen sisäiseen verkkoliikenteeseen.

* Verkkoliitännän nimen alkuosa kertoo yhteyden tyypin. en tarkoittaa kiinteää Ethernet-yhteyttä, wl langatonta Wi-Fi-yhteyttä ja lo loopback-liitäntää.

* Omia verkkoliitäntöjä voidaan tarkastella komennolla ip a ja reititystietoja komennolla ip route

#  b) Ei voi kalastaa

Aloitin testaamalla internetyhteyttä Kali Linuxissa komennolla:

    ping 8.8.8.8

Samalla seurasin verkkoliikennettä Wiresharkilla ja huomasin, että ICMP-paketteja alkoi kulkea.

Seuraavaksi katkaisin verkkoyhteyden komennolla:

    sudo ip link set dev eth0 down

Komento poisti eth0-verkkoliitännän käytöstä, jolloin internetyhteys katkesi ja ping-pakettien kulku loppui Wiresharkissa.

Lopuksi otin verkkoliitännän takaisin käyttöön komennolla:

    sudo ip link set dev eth0 up

Tällä komennolla verkkoyhteyden sai jälleen käyttöön.
